# Technical Evidence

This directory contains selected non-sensitive evidence from the AWS EC2 JupyterLab laboratory.

## Included Evidence

### AWS EC2 SSH Session

`aws-ec2-ssh-session.png`

Shows a successful authenticated session on the Ubuntu Server EC2 instance.

### EC2 Storage Validation

`aws-ec2-disk-usage-df-h.png`

Shows storage and filesystem validation performed on the Ubuntu EC2 instance using the `df -h` command.

Only evidence that can be clearly associated with this AWS laboratory is included here. Credentials, private keys, authentication tokens, and public infrastructure addresses are intentionally excluded.
